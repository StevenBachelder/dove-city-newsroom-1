# Badge Taxonomy ↔ MPF Information-Influence Typology — Cross-walk (v1 draft)

Working mapping to Falkheimer & Pamment (2026) framework categories as used in MPF materials (deceptive identities · fabricated/manipulated content · malign rhetoric · symbolic/technical amplification). **Verify against the final textbook chapters before citing.**

| Game badge (technique) | MPF-family category | Notes / operation stage |
|---|---|---|
| Manipulated media | Manipulated content | Edited authentic material; L1 crude edit → L3 fully AI-generated (synthetic content) |
| Fabricated event / hoax | Fabricated content | Event invented outright (BAD DOG death) |
| Out-of-context | Manipulated context | Authentic material, false framing; the storming crop = context removal as weapon |
| Unverified claims | (Rhetoric) claim-laundering | "Sources say" without confirmable origin; tests sourcing discipline |
| Conspiracy framing | Malign rhetoric / narrative | Hidden-hand explanation grafted onto real footage (Red Bull convoy) |
| Polarization | Malign rhetoric — identity targeting | Us-vs-them enemy construction; cf. Hedling (2025) |
| Emotion ≠ false | (Defence-side concept) | Not an attack technique: an inoculation against over-flagging; no MPF attack equivalent — a deliberate addition |
| Ad-Spotter | Deceptive identity / commercial camouflage | Sponsored content dressed as results |
| — (fiction layer) | Coordinated inauthentic amplification + symbolic act | CityTruth astroturf echoes; the physical attack on the station |

Gap noted for future content: deceptive *sender identity* (imposter accounts of real institutions) is only lightly exercised — candidate for a future case.
