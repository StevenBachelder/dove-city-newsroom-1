## Part 3 — OUTLIERS: techniques the posts already perform that the badge list doesn't name

These live in the library as *post-level* phenomena. Ranked by how strongly the material already teaches them — the top tier are, in effect, Game 2's new badges waiting to be minted:

1. **AMPLIFICATION** — reposting with added urgency, not information ("For Our Public Safety": *"RT before they delete it"*). The trap note already teaches it verbatim.
2. **INSINUATION** — "sources claim" journalism-cosplay; guilt by adjacency (escort photos, body-language reads). #13 is entirely built of it.
3. **DENIALISM / REFLEXIVE DISBELIEF** — "storm panic is fake," "sky's calm in MY neighborhood," the wrongful-flag bait. The deck teaches it as the *mirror* failure, but it is a technique actors deploy deliberately (the liar's dividend, weaponized).
4. **FEAR COMMERCE** — the sponsored ring as a persuasion strategy in itself, distinct from mere advertising: manufacturing the anxiety the product answers.
5. **PRE-NARRATION** — prophecy as template (The Fish Lovers predicting collapse before any convoy existed); footage arrives later to fit it.
6. **COMPOUNDING / BOILERPLATE REUSE** — one debunked wave cited as the next wave's evidence (the Scapegoat Thread). Arguably the most important adult-world technique in the whole library.
7. **PRE-PLANTED ALIBI / SEEDING** — @BadDogStudios' post *before* the rumors; content placed in advance to be "discovered."
8. **ASTROTURFING** — the same image/claim appearing "everywhere" from one source (water's recirculation; ICPAA's manufactured consensus).
9. **ENGAGEMENT BAIT** — deletion-panic, "share before it's too late," countdown urgency: form-level manipulation independent of content.

## Design thoughts for Game 2 (offered, not prescribed)

**The binary was the training wheels; multi-labeling is the bicycle.** The single most valuable inheritance is that most posts carry *more than one* technique — so Game 2's core mechanic almost designs itself: not "which technique?" but "which techniques, and which is load-bearing?" Difficulty = label density (L1: one clean technique per post; L3: #15's four-layer stack).

**One canon, two games.** Extend `cases.js` posts with a `techniques:[]` array (the way `sender` was added — same sweep method, batches by level). Then both games read the *same files*: City News ignores the labels; Game 2 is built on them. Every future case authored once serves both — and the intern-lesson framing is literally true: Game 2 studies Game 1's archive, as interns study the desk's back catalogue.

**The census is a mechanic waiting.** Sender × technique is a matrix players could *discover*: RedAlertWatch's techniques across three cases, securitysource.com's signature move. "Name the actor's repertoire" is a Level-3-of-Game-2 exercise no other media-literacy game can offer, because no other has the annotated ecosystem.

**Genuine posts are load-bearing.** Keep the true stories in the library. A technique-naming game without "none — it's real" as a valid answer teaches paranoia, not analysis — the same both-errors-count principle, one level up.

**Outlier promotion is the badge roadmap.** Tiers 1–3 above (amplification, insinuation, denialism) have complete teaching material *already in the deck* — posts, trap notes, verdicts. They can be Game 2 badges on day one. Tiers 4–9 are the expansion path.
